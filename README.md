# Student-registration
Student Information Registration - Activity 1

Student Registration Form

Overview

The Student Registration Form is a responsive, single-file HTML project for collecting student information through a clean and user-friendly interface. HTML, CSS, and JavaScript are included in the same file.

Technologies

HTML5: Form structure and content

CSS3: Layout, styling, responsive design, and media containers

JavaScript: Validation, media previews, remove controls, reset behavior, and success messages

Features

Student information fields

Course/program selection

Interests selection

Document upload

Profile picture upload and preview

Embedded profile picture

Embedded audio player

Audio title: Taylor Swift - Fate of Ophelia

Embedded video player

Choose File and Remove buttons positioned beside each other

Media preview and removal controls

Form validation

Success confirmation modal/message

Responsive desktop and mobile layout

How to Run

Download the HTML file.

Save it with an .html extension if necessary.

Open it in Google Chrome, Microsoft Edge, or Firefox.

Complete the registration fields.

Test the document, profile picture, audio, and video upload controls.

Test the Remove and Reset controls.

Submit the form to view the success message.

No web server is required for basic local testing.

Media Upload Instructions

Profile Picture

Click Choose File in the Profile Picture section.

Select an image.

Review the preview.

Use Remove Profile to remove the selected image.

Audio

Click Choose File in the Audio section.

Select an audio file.

Use the audio player controls.

Click Remove Audio to remove the selected audio.

Video

Click Choose File in the Video section.

Select a video file.

Preview the video using the player.

Click Remove Video to remove the selected video.

Important Notes

This is primarily a front-end application.

The success message does not permanently save registration records unless a backend and database are connected.

Selected files are handled locally by the browser.

Embedded media can increase the HTML file size.

Browser support depends on the media format.

Protect personal student information and do not share it publicly without permission.

Ensure that you have the appropriate rights or permission to use copyrighted audio.

Troubleshooting

Media does not play

Use an updated browser.

Confirm that the embedded source was not modified.

Check whether the browser supports the media format.

Refresh the page and test again.

Form cannot be submitted

Complete all required fields.

Check the browser's validation messages.

Verify that email and other required values are valid.

Preview disappears

Use the reset function, if available, to restore embedded media.

Select a new file using the relevant Choose File button.
